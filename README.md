# Mechanics – KoNaR Becard

Mechanical designs, CAD models, and manufacturing files for the KoNaR Becard drone.

### Contents
- `cad/` – 3D CAD models and assemblies
- `exports/` – STL (3D printing), STEP, and DXF (CNC) files
- `docs/` – Technical drawings, BOM, and assembly guides

### Notes
- Always export standardized `.step` files alongside native CAD files.
- Use Git LFS for large binary files (>50 MB).
